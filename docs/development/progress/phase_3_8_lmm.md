## Summary

Phase 3.8 implements the LIBOR Market Model (LMM), also known as the BGM model. This is the industry standard for pricing complex interest rate derivatives, modeling the evolution of multiple forward LIBOR rates with correlation.

## Deliverables

### 1. LMM Core Model

**File:** `src/models/forward_rate/lmm.py`

Implemented components:

- **LMMCorrelation**: Correlation structures for forward rates
  - Flat correlation: $\rho_{ij} = \rho$
  - Exponential decay: $\rho_{ij} = e^{-\beta|T_i - T_j|}$
  - Custom user-defined matrix
  - Cholesky decomposition for simulation

- **LMMParameters**: Model parameters
  - Tenor structure ($T_0, ..., T_n$)
  - Accrual factors ($\tau_i$)
  - Initial forward curve ($F_i(0)$)
  - Volatility term structure ($\sigma_i$)
  - Parameter validation

- **LMMDynamics**: Monte Carlo simulation
  - Log-Euler discretization
  - Spot measure drift correction (no-arbitrage)
  - Antithetic variates for variance reduction
  - Correlated Brownian motion via Cholesky

- **LMMSimulation**: Simulation results
  - Forward rate paths: $(n_{paths}, n_{forwards}, n_{steps}+1)$
  - Numeraire (rolling bank account)
  - Discount factors

### 2. Pricing Functions

- **price_caplet()**: MC pricing for caplets
- **price_floorlet()**: MC pricing for floorlets
- **price_swaption()**: MC pricing for European swaptions (payer/receiver)

## Key Design Decisions

### 1. Spot Measure Implementation

Chose the spot (rolling bank account) measure because:
- Most intuitive for practitioners
- Numeraire is always positive
- Drift correction is well-defined

### 2. Log-Euler Discretization

Used log-Euler scheme:
$$F_i(t+\Delta t) = F_i(t) \cdot \exp[(\mu_i - \sigma_i^2/2)\Delta t + \sigma_i\sqrt{\Delta t}Z_i]$$

Benefits:
- Preserves positivity of forwards
- Good balance of accuracy and speed
- Simple implementation

### 3. Correlation via Cholesky

Correlated Brownian motions generated by:
$$Z = L \cdot \xi$$

Where $L$ is the Cholesky factor and $\xi$ are independent normals.

### 4. Antithetic Variates

Built-in support for antithetic variates:
- Reduces MC variance
- Uses $(Z, -Z)$ pairs
- Especially effective for European options

## Mathematical Details

### Drift Correction Formula

Under the spot measure:
$$\mu_i(t) = \sum_{j=\beta(t)}^{i} \frac{\rho_{ij} \sigma_i \sigma_j \tau_j F_j(t)}{1 + \tau_j F_j(t)}$$

This ensures:
- No-arbitrage (consistent with bond prices)
- Forwards are martingales under appropriate measure
- Caplet prices match Black's formula

### Swaption Pricing

Forward swap rate at exercise:
$$S(T) = \frac{1 - P(T, T_n)}{A(T)}$$

Where $A(T) = \sum_{j} \tau_j P(T, T_{j+1})$ is the annuity.

## Usage Example

```python
from src.models.forward_rate import (
    LMMCorrelation,
    LMMParameters,
    LMMDynamics,
)
import numpy as np

# Setup
n = 8
tenors = np.linspace(0.0, 2.0, n + 1)
tau = np.full(n, 0.25)
f0 = 0.03 + 0.001 * np.arange(n)
vol = np.full(n, 0.20)

corr = LMMCorrelation(n_forwards=n, correlation_type="exponential", beta=0.1)
params = LMMParameters(tenors=tenors, accrual_factors=tau,
                       initial_forwards=f0, volatilities=vol, correlation=corr)
dynamics = LMMDynamics(params)

# Price 1Yx1Y swaption
price = dynamics.price_swaption(start_index=4, end_index=8, strike=0.035,
                                 is_payer=True, n_paths=100000, seed=42)
print(f"Swaption price: {price * 10000:.2f} bp")
```
